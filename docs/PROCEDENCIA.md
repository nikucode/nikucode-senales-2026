# Procedencia y límites de la documentación

Selección del archivo de investigación nikucode, preparada antes y durante el evento con autorización de Makana para investigar, tener ideas y llevar material escrito. La app se desarrolla durante el evento; este bloque no importa código ni historia de desarrollo anterior.

Se importaron informes, matriz/especificación, programa, preparación técnica, guion y borradores de presentación. Se adaptaron rutas/enlaces para portabilidad; referencias históricas excluidas se identifican como tales. No están todos los papers descargados, logs locales ni archivos históricos. No se importa el historial completo de conversaciones, perfiles globales ni datos personales.

La lectura de fuentes, sus límites y las decisiones están en los informes. La documentación no acredita eficacia propia, pruebas de app ni elección definitiva de stack/branding. Las versiones de herramientas del documento técnico pertenecen al equipo donde se inspeccionaron, sin garantizar las del otro integrante.

PDF: cinco páginas renderizadas/revisadas. ODP: estructura ZIP/XML comprobada, apertura en Impress pendiente. Ambos son borradores y necesitan captura/demo/resultados reales antes de presentar.

MANIFIESTO_IMPORTACION.json registra hashes del contenido original y su copia inicial adaptada. Si se editan documentos después, el manifiesto sigue describiendo esta importación, no hashes vigentes. El repositorio Git conserva modificaciones posteriores.
